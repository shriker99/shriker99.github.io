LibrarianConnector Privacy Policy

Last updated: September 30, 2026

LibrarianConnector is a personal tool used only by its owner, Brian Coburn, to search his own Gmail.

What it accesses

LibrarianConnector requests read-only access to Gmail using the gmail.readonly scope. It cannot send, delete, or change any email.

Where data is stored

Email data is processed and stored only on the owner's personal computer. It is not uploaded to any server run by LibrarianConnector.

Sharing

No data is sold, shared, or sent to third parties.

Access tokens

Google access tokens stay on the owner's personal computer and are never sent anywhere else.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
